Política de Privacidad — Bot de Mantención Patagónica

Esta página describe cómo Patagónica Inmobiliaria / Campo Mar SPA / Evox-Sánchez Hermanos SpA ("Patagónica") trata los datos recibidos a través del bot de mensajería (WhatsApp y Telegram) usado para reportar solicitudes de mantención de arrendatarios.

Qué datos recibimos

Cuando un arrendatario escribe al bot, recibimos: el número de teléfono o usuario de la cuenta que escribe, el RUT que el arrendatario proporciona para identificarse, y el contenido de los mensajes enviados para describir la incidencia (ej. categoría del problema).

Para qué se usan

Estos datos se usan exclusivamente para identificar al arrendatario contra nuestros registros de contratos vigentes y crear una Orden de Trabajo de mantención en nuestro sistema interno (OCFast), de forma que el equipo de Operaciones de Patagónica pueda atender la solicitud.

Dónde se almacenan

Los datos se guardan en una base de datos privada (Supabase) de uso exclusivo de Patagónica, con acceso restringido a personal autorizado de Operaciones. No se comparten con terceros ni se usan con fines publicitarios.

Eliminación de datos

Un arrendatario puede solicitar la eliminación de sus datos de contacto almacenados escribiendo a operaciones@patagonica.cl, indicando su RUT o número de teléfono.

Contacto

Para cualquier consulta sobre esta política, escribe a operaciones@patagonica.cl.
